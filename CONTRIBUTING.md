# Contributing

The canonical repository is owner-maintained. Public users have read and download
access, not direct write access.

Bug reports and narrowly scoped pull requests are welcome. A pull request changes
nothing in the canonical repository unless the owner explicitly reviews and
merges it. Please do not include workbooks, review outputs, credentials, tokens,
or other private material in issues or pull requests.

Before proposing a code change, run:

```powershell
npm install
npm test
```
